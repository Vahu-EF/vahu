THE FOUNDATION

A system around the work.

Keep engineering decisions visible, reusable, and grounded in the project you’re building.

01

Standards

Fifteen accepted engineering standards cover architecture, testing, security, documentation, and decision-making.

Browse core standards ↗
02

Project context

Record identity, ownership, technology choices, repositories, design-system status, and readiness in a versioned configuration.

Read the configuration guide ↗
03

Technology profiles

Three initial profiles describe Node.js backend, PostgreSQL, and Vitest practices. Profiles are optional; none is applied by default.

Explore the profile catalog ↗
04

Workflows & quality gates

Fourteen lifecycle workflows and thirteen gates define expected inputs, evidence, approvals, and failure states. They are not a command runner.

TRY IT LOCALLY

Run a first local pass.

The project is not published to npm yet. Clone the repository to use the current CLI.

  1. 01

    Get the source

    Use Node.js 22+ and pnpm 10+.

  2. 02

    Run the checks

    Build and test the workspace locally.

  3. 03

    Inspect an example

    Every committed example is validated in the test suite.

# Clone and enter the repository
git clone https://github.com/Vahu-EF/vahu.git
cd vahu

# Install, verify, and inspect
pnpm install
pnpm check
pnpm dev -- project inspect --path examples/backend-project
pnpm dev -- profile list
