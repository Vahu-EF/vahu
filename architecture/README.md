# Architecture

This folder records the decisions and boundaries behind the VAHU foundation.

| Area                              | Contents                             |
| --------------------------------- | ------------------------------------ |
| [Decisions](decisions/)           | Architecture Decision Records        |
| [Diagrams](diagrams/)             | Small text-based system diagrams     |
| [Specifications](specifications/) | Phase-level implementation contracts |

The primary product document is [`VAHU.md`](../VAHU.md). An ADR records a
decision that is hard to reverse; it does not replace the product foundation.
