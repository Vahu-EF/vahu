# VAHU documentation

This folder contains human-facing documentation for the VAHU repository. The
authoritative product foundation is [`VAHU.md`](../VAHU.md); these pages explain
the current implementation and how to work with it. The documentation and
website are being improved in Phase 7; this is not yet a complete documentation
site.

| Area                                        | What it covers                                               |
| ------------------------------------------- | ------------------------------------------------------------ |
| [Getting started](getting-started/)         | Install, run the workspace, and make a first validation pass |
| [Concepts](concepts/)                       | Framework boundaries, project configuration, and readiness   |
| [Guides](guides/)                           | Task-oriented Phase 0 guidance                               |
| [CLI](cli/)                                 | Implemented commands and their limits                        |
| [Framework](framework/)                     | Where reusable framework content belongs                     |
| [Technology profiles](technology-profiles/) | The one canonical profile location and profile contract      |
| [Contributing](contributing/)               | Development, review, and release preparation                 |

The docs use three status labels:

- **Implemented** — present in this repository and covered by a check or test.
- **In Progress** — scaffolded, but not complete or not yet published.
- **Planned** — described for future work, with no working implementation.
