# Code of Conduct

VAHU is an open engineering project. We want technical discussion to be direct,
respectful, and useful to people with different backgrounds and experience
levels.

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected behavior

- Discuss ideas and code, not people.
- Give specific, actionable feedback.
- Assume good faith while asking for evidence.
- Respect differing experience, identity, language, and technical choices.
- Credit other people’s work.
- Keep issues and pull requests focused on the project.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Sexualized language or attention.
- Publishing someone’s private information without permission.
- Deliberately disrupting discussions or repeatedly ignoring maintainer
  direction.
- Retaliation against someone who reports a concern.

## Scope

This code applies in repository discussions, issues, pull requests, reviews, and
other project spaces. It also applies when someone is representing VAHU in a
public space.

## Reporting and enforcement

Report a concern privately to the repository maintainers through GitHub. If the
repository has private vulnerability reporting or a maintainer contact listed in
the organization profile, use that channel rather than a public issue.

Maintainers will review reports in good faith, protect the reporter’s privacy
where possible, and choose a proportionate response. Responses may include a
private warning, a request to edit or remove content, temporary participation
limits, or removal from project spaces.

No specific enforcement contact has been invented for Phase 0. The organization
owners should publish a dedicated contact before the project accepts broad
public participation.
