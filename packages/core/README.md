# @vahu-ef/core

Reusable project validation and diagnostics for VAHU. This package does not
depend on the CLI, so other tools can load the same configuration rules.

## Status

Early Phase 0 preparation. This package is **not published to npm yet**.

The public API includes project configuration loading, readiness assessment,
validation, and environment diagnostics. See the source in
[`packages/core`](https://github.com/Vahu-EF/vahu/tree/main/packages/core).
