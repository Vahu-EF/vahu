# Technology profiles

Status: **Planned**.

This is the **only canonical technology-profile location**. There is no root
`profiles/` directory.

Profiles will be modular by category: backend, frontend, mobile, database,
infrastructure, testing, and deployment. A project selects only the profiles it
needs. See [the profile template](PROFILE_TEMPLATE.md) and
[the public guide](../../../docs/technology-profiles/README.md).

Do not describe a profile as supported until its content, required tools, checks,
and limitations are documented and tested.
