# @vahu-ef/schemas

Versioned configuration contracts for VAHU projects.

## Status

Early Phase 0 preparation. This package is **not published to npm yet**.

The source of truth is the Zod schema in
[`src/project.ts`](https://github.com/Vahu-EF/vahu/blob/main/packages/schemas/src/project.ts).
A generated JSON Schema is committed at `project.schema.json`.

No public schema URL is claimed in Phase 0. See the
[configuration guide](https://github.com/Vahu-EF/vahu/blob/main/docs/concepts/project-configuration.md).
