# Templates

Status: **Planned**.

Templates are files intended to be copied or generated into a user project.
They are not runtime dependencies of the CLI.

| Folder           | Intended use                             |
| ---------------- | ---------------------------------------- |
| `project/`       | Minimal project foundation               |
| `repository/`    | Repository policies and community files  |
| `documentation/` | README, ADR, and documentation structure |
| `agents/`        | Agent-neutral instruction files          |
| `ci-cd/`         | Provider-neutral CI/CD starting points   |
| `design-system/` | Design tokens and approval records       |

Phase 0 reserves the structure. No template is promised as complete.
