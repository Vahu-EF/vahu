# Templates

Status: **Partial**.

Templates are files intended to be copied or generated into a user project.
They are not runtime dependencies of the CLI.

| Folder           | Intended use                             | Status      |
| ---------------- | ---------------------------------------- | ----------- |
| `project/`       | Minimal project foundation               | Planned     |
| `repository/`    | Repository policies and community files  | Planned     |
| `documentation/` | README, ADR, and documentation structure | In Progress |
| `agents/`        | Agent-neutral instruction files          | Planned     |
| `ci-cd/`         | Provider-neutral CI/CD starting points   | Planned     |
| `design-system/` | Design tokens and approval records       | Planned     |
